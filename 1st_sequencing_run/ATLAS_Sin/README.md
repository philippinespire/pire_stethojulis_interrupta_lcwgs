<details><summary>2. Binning GERP scores</summary>

### 2. Binning GERP scores

To generate bed files based on binned GERP scores for ATLAS, you will have to process the `reference.denovoSSL.Sin20k.ancestral.rates.gz` file generated by GenErode. So far we have used three bins (sites with scores >1.5, sites with scores between 1.0 and 1.5, and sites with scores between 0.5 and 1).  
```
# move to your species ATLAS directory

cd /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin

# get sites with scores in each particular bin using the reference.denovoSSL.Sin20k.ancestral.rates.gz file from GenErode

gunzip -c /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/GenErode_Sin_20k/results/gerp/reference.denovoSSL.Sin20k.ancestral.rates.gz | awk -v OFS='\t' '($4 >= 1.5) {print $1,$2,$2}' > gerp_15.bed 

gunzip -c /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/GenErode_Sin_20k/results/gerp/reference.denovoSSL.Sin20k.ancestral.rates.gz | awk -v OFS='\t' '($4 >= 1 && $4 < 1.5) {print $1,$2,$2}' > gerp_10.bed 

gunzip -c /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/GenErode_Sin_20k/results/gerp/reference.denovoSSL.Sin20k.ancestral.rates.gz | awk -v OFS='\t' '($4 >= 0.5 && $4 < 1) {print $1,$2,$2}' > gerp_05.bed 
```

Check the number of sites in your `gerp_\*.bed` files. ATLAS wants something on the order of ~5 million total sites for its recalibration procedure. If the default bins do not generate ~5 million total sites, then adjust the lower bin threshhold of 0.5 down to capture more sites. You can move forward with just two bins if necessary. 
```
wc -l gerp_15.bed
363660

wc -l gerp_10.bed 
464350

wc -l gerp_05.bed 
838027
```
1,666,037 total sites. Too few. Adjust bins to get more sites.

Sites with scores >1.5, sites with scores between 0.9 and 1.5, and sites with scores between 0.3 and 0.9.

gunzip -c /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/GenErode_Sin_20k/results/gerp/reference.denovoSSL.Sin20k.ancestral.rates.gz | awk -v OFS='\t' '($4 >= 0.3 && $4 < 0.9) {print $1,$2,$2}' > gerp_03.bed

Merge adjacent sites into regions using bedtools.
```
module load bedtools

crun bedtools merge -i gerp_15.bed > gerp_15.merge.bed 

crun bedtools merge -i gerp_08.bed > gerp_08.merge.bed 

crun bedtools merge -i gerp_01.bed > gerp_01.merge.bed 
```

Remove singleton sites from `gerp_\*.merge.bed` files.
```
awk -v OFS='\t' '!($2==$3)' < gerp_15.merge.bed > gerp_15.merge.nosingle.bed 

awk -v OFS='\t' '!($2==$3)' < gerp_08.merge.bed > gerp_08.merge.nosingle.bed 

awk -v OFS='\t' '!($2==$3)' < gerp_01.merge.bed > gerp_01.merge.nosingle.bed 
```

Copy all .bed files to the recal directory, which is the output directory for the recalibration step.

<details><summary>3. Run Recalibration</summary>

### 3. Run Recalibration

ATLAS has its own recalibration procedure, so you will use the '\*merged.rmdup.merged.realn.bam' files produced by GenErode before it performs its recalibration. This step will have to be run separately on the modern and historical files, unless they are all in the same directory. 

Modify the last line of the `atlas_recal_readuntilbeds_array.bash` script to reflect the path for the `atlas_recal_readuntilbeds_array.sbatch` script.
```
/archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin/atlas_recal_readuntilbeds_array.sbatch ${BAMDIR} ${REFLOC} ${OUTDIR})
```

Modify the last line of the `atlas_recal_readuntilbeds_array.sbatch` script to reflect the file names of the `gerp_15.merge.nosingle.bed,gerp_08.merge.nosingle.bed,gerp_01.merge.nosingle.bed` files.
```
crun.atlas atlas --task estimateErrors --bam ${sample_name}.merged.rmdup.merged.realn.bam --fasta ${REFLOC} --regions gerp_15.merge.nosingle.bed,gerp_08.merge.nosingle.bed,gerp_01.merge.nosingle.bed --readUpToDepth 10
```

#### Historical

Run ATLAS recalibration with `atlas_recal_readuntilbeds_array.bash` on historical samples.
```

<details><summary>5. Run Theta</summary>

### 5. Run Theta

The ATLAS theta step will estimate theta for both historical and modern samples using the whole `\*merged.rmdup.merged.realn.bam` files from the recalibration step. It also performs downsampling. This step also requires the `\*.merged.rmdup.merged.realn_RGInfo.json` files as input. 

Modify the last line in the `atlas_theta_albrecal_array.bash` script to reflect the path for the `atlas_theta_albrecal_array.sbatch` script.
```
nano atlas_theta_albrecal_array.bash

/archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin/atlas_theta_albrecal_array.sbatch ${BAMDIR} ${OUTDIR})
```

Run ATLAS theta with `atlas_theta_albrecal_array.bash`. 
```
# change directory to your ATLAS_Sin directory
cd /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin

bash atlas_theta_albrecal_array.bash [directory with recalibrated output files] [output directory]

bash atlas_theta_albrecal_array.bash /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin/recal /archive/carpenterlab/pire/pire_stethojulis_interrupta_lcwgs/1st_sequencing_run/ATLAS_Sin/theta
